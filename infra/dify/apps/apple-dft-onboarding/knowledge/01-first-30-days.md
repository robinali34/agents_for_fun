# First 30 days — settle in

Goal: **access + context + trust**, not heroics.

## Week 0–1 (logistics)

- [ ] Badge, laptop, accounts, VPN / network, MFA
- [ ] Required security / compliance training complete (or scheduled)
- [ ] Calendar: 1:1 with manager, buddy / onboarding buddy if assigned
- [ ] Locate team wiki / repo index **only in approved Apple systems** — do not copy proprietary content into this assistant
- [ ] Confirm: org chart, your manager’s expectations for the first month

## Week 1–2 (role clarity)

Ask your manager (adapt wording):

1. What does success look like at day 30 / 60 / 90 for this role?
2. Which 2–3 systems or codebases should I learn first?
3. Who are the go-to people for DFT SW, lab, silicon, and test infrastructure?
4. What decisions can I make alone vs escalate?
5. How does the team run reviews, on-call, and release / tapeout-adjacent freezes?

## Week 2–4 (first useful contribution)

Prefer a **small, visible, low-risk** win:

- Fix a flaky test harness or improve logging in a tool you own with a buddy
- Document an onboarding gap you hit (in the team’s approved doc space)
- Shadow a bring-up / lab session and write *personal* reflection notes (no secrets)

## Daily habit (15 minutes)

1. Three bullets: done / blocked / next
2. One learning note (concept, acronym, or workflow)
3. One relationship touchpoint (async thank-you or clarifying question)

# Weekly review ritual

Every Friday (or Sunday), 20 minutes:

1. **Shipped** — what landed?
2. **Learned** — one technical + one org insight
3. **Stuck** — blockers and who can unblock
4. **Next week** — top 3 outcomes (not a task dump)
5. **Energy** — 1–10; adjust load with manager if needed
6. **Relationships** — one person to thank or clarify with

Optional prompt for the assistant:

> Here is my raw weekly dump: … Turn it into a manager-ready update and a personal focus list for next week. Flag anything that looks like it might be confidential and omit it.

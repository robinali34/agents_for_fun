# Days 31–90 — deepen and deliver

## Days 31–60

- Own a **bounded** project end-to-end (design note → implementation → review → landing)
- Map dependencies: who blocks you, what SLAs exist for lab / silicon / CI
- Build a personal glossary of team acronyms (store only non-confidential terms here)
- Present a short “what I learned / what I’ll do next” in a team forum if appropriate

## Days 61–90

- Propose one improvement with **cost / risk / benefit** (tooling reliability, test time, debug UX)
- Clarify growth: technical ladder expectations for Senior SWE in this org
- Agree with manager on a medium-term theme (e.g. DFT automation quality, data pipelines, developer experience for hardware test)

## Senior IC behaviors that travel well

- Write the decision down before debating it
- Separate **facts / assumptions / asks**
- Prefer reversible experiments over big-bang rewrites
- Protect deep-work blocks; batch meetings when possible
- Escalate early with options, not only problems
